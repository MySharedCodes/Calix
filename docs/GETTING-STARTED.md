# 快速上手 / Get Started

从安装完成开始，走完计算、绘图和保存。安装条件见[安装说明](INSTALLATION.md)。英文入口见 [English README](../README.md)。

## 1. 创建笔记本

打开 Calix，等右上角显示引擎就绪。点击左侧“新建笔记”，在标题处输入名称。把下面代码粘贴到计算单元，按 **Ctrl+Enter**：

```wolfram
1/3 + 1/6
N[Pi, 30]
UnitConvert[72[km/h], "m/s"]
```

结果依次为 `1/2`、30 位精度的 π 和 `20[m/s]`。精确分数不会自动变成小数；需要小数时使用 `N[表达式, 有效位数]`。

## 2. 定义变量并求解

在下一计算单元输入：

```wolfram
m = 2[kg];
v = 3[m/s];
1/2 m v^2
Solve[x^2-5*x+6 == 0, x]
```

动能为 `9[J]`，方程根为 2 和 3。`=` 赋值，`==` 建立方程；`m`、`v` 可供本笔记本后续单元使用。赋值后的 `;` 隐藏中间输出。

## 3. 求一个微分方程

```wolfram
DSolve[{y'[t]+2*y[t]==0, y[0]==3}, y[t], t]
```

输出对应 $y(t)=3e^{-2t}$。`y'[t]` 表示对时间求导，`y[0]==3` 是初值。并非所有 ODE 都有解析解；数值初值问题见[使用帮助](USER-GUIDE.md)。

## 4. 绘图和播放动画

```wolfram
Plot[3 Exp[-2 t], {t,0,3}]
```

先点击图形，再用滚轮缩放；未激活图形时滚轮滚动页面。另一单元可输入：

```wolfram
Animate[Plot[Sin[x-a], {x,0,2 Pi}], {a,0,2 Pi}]
```

点击播放或拖动进度条。图形工具栏可以重置视图、导出 PNG。

## 5. 加说明并保存

点击“文字单元”，输入 Markdown。行内数学用 `$...$`，独立公式用 `$$...$$`，例如 `$E=mv^2/2$`。Shift+Enter 结束文字编辑并预览。

Ctrl+S 保存 `.cixnb`。“另存为”或 Ctrl+Shift+S 保存到另一条路径。工作空间自动保存便于恢复界面，但重要笔记应另存为磁盘文件。

再次打开文件会显示输入和输出，变量定义不会自动执行。需要依赖旧变量时，先点“全部运行”。
