## 离线阅读

仓库与便携版中的 Markdown 可在支持 Markdown 的编辑器中阅读。软件“帮助”入口和 F1 提供随应用编译的离线文档；不需要访问外部网站，也不会执行文档中的代码。首页展示使用 `docs/images/` 中的真实截图。
