# 案例目录

完整案例在侧栏“计算示例”的上半部分，点击后作为独立笔记本打开；下方的函数演示向当前文档追加计算单元，多次点击可以得到不同输入。函数演示不应覆盖自己正在编辑的内容。

先尝试 [空气阻力](../examples/00-projectile-with-air-resistance.calix)，或用 [快速上手](GETTING-STARTED.md) 中的短表达式。打开案例后用“全部运行”建立变量，再修改参数。案例标题会随界面语言显示，下面链接的是实际文件名。

## 力学与电磁学

| 案例 | 可以观察什么 |
|---|---|
| [空气阻力](../examples/00-projectile-with-air-resistance.calix) | 从带单位参数求阻力系数；比较线性阻力解析解与二次阻力数值解 |
| [弹性双摆](../examples/弹性双摆-两段弹簧与两个小球.calix) | 小振幅近似和大振幅数值运动，动画展示后者 |
| [五球弹簧串](../examples/五球弹簧串-松手下落.calix) | 松手后的运动，以及底部两球与自由落体的比较 |
| [多天体运动](../examples/多天体-平面与三维引力运动.calix) | 平面、三维轨道和引力势场 |
| [电流线圈](../examples/电流线圈附近的带电粒子.calix) | 线圈、磁感线、场切片和不同电荷的轨迹 |
| [类氢离子](../examples/类氢离子-薛定谔方程解析解.calix) | 从薛定谔方程求径向解、验证波函数，观察多种原子态概率密度 |
| [格点色动力学](<../examples/格点色动力学-SU(3) 规范场与 Wilson 环.calix>) | 离散规范场、作用量与 Wilson 环的教学计算 |

## 工程 PDE

以下数值案例需要安装可选 **PDE module**。建议先保存文档、关闭不需要的任务，按照案例参数运行；细化网格可能显著增加时间和内存。

| 案例 | 模型与输出 |
|---|---|
| [吊桥](../examples/吊桥-混合维有限元受力分析.calix) | 3D 桥塔、2D 桥面、1D 索耦合，位移、平衡检查与应力 |
| [机翼](../examples/机翼-稳态流场与湍流闭合.calix) | 二维定常流与代数黏度闭合，速度场叠加流线 |
| [波动光学](../examples/波动光学-石英与空气的反射和折射.calix) | 斜入射到界面，反射、透射与场分布 |
| [齿轮](../examples/齿轮啮合-接触与扭矩传递.calix) | 二维接触与圆角齿根，应力和局部网格 |

这些是教学和求解器验证模型。二维齿轮不是完整三维斜齿轮；桥塔连接处、接触应力峰值和湍流闭合都有分辨率及模型限制。先读 [PDE 说明](PDE.md)，不要直接把例子的云图当成工程安全结论。

- [显式数值计算](../examples/显式数值计算.calix)：每组十行，含矩阵、复数、求和、求积与特殊函数。
- [单位换算与运算](../examples/单位换算与运算.calix)：带单位输入、转换、组合与简化。
- [代数方程组](../examples/代数方程组.calix)、[因式分解](../examples/因式分解.calix)、[级数展开](../examples/级数展开.calix)、[复数化简](../examples/复数化简.calix)。
- [解析最值](../examples/解析最值.calix)、[数值最值](../examples/数值最值.calix)、[微分方程解析解](../examples/微分方程解析解.calix)、[偏微分方程解析解](../examples/偏微分方程解析解.calix)。
- [描述统计](../examples/描述统计.calix)、[概率分布](../examples/概率分布.calix)、[假设检验](../examples/假设检验.calix)、[数据拟合](../examples/数据拟合.calix)。
- [三维曲面](../examples/三维曲面.calix)、[二维参数曲线](../examples/二维参数曲线.calix)、[等高线](../examples/等高线.calix)、[动画](../examples/动画.calix)。

要编写自己的案例，建议用文字单元说明问题、参数、模型假设和单位，推导与验证放在计算单元。提供能从干净会话“全部运行”的文件，并说明输出如何检查。详见 [贡献指南](../CONTRIBUTING.md)。
