# Calix 0.1.9

- Removed the Unit calculator sidebar button. Unit operations run in calculation cells, with automatic simplification after suffix input and arithmetic. Explicit UnitConvert preserves the requested output unit.
- Accepts 1[m], 1["m/s"], standalone [kg*m/s^2], assigned v[m/s], vector suffixes and unassigned lowercase symbolic x["m"]. Bare f[t] remains a mathematical function. Recognized suffixes do not depend on notebook variable values.
- Uses the installed Pint definitions, added Chinese aliases and prefixed forms. The editor includes a generated catalog of 1,767 names and prefixed aliases. Supports micro signs, ohm signs, quoted degree temperatures and quoted superscript powers. Case matters: m and M are different. Input suggestions appear inside numerical or standalone unit brackets.
- Compound SI expressions reduce to named derived units and short products when possible, such as N, J, W, Pa*s and W/K. Simple user units and prefixes are retained. Dimensionless results omit empty brackets; affine temperatures retain Pint's rules. UnitConvert remains available for a specific target representation. Dimensional equivalence cannot infer physical meanings such as torque versus energy.
- Added the current-loop charged-particle notebook. It computes the analytic on-axis field, physical proton scales, a center-uniform-field analytic helix, and the exact off-axis circular-loop field using complete elliptic integrals. Lorentz motion in the nonuniform field is numerical. The off-axis formula excludes the symmetry axis and the ideal wire; the stated orbit avoids both. Speed conservation and independent Biot-Savart line quadrature are tested.
- Added the hydrogen-like ion notebook. It presents the regular confluent-hypergeometric radial solution, computes the series recurrence residual and termination condition, evaluates exact bound-state energies, and constructs the normalized He+ 3p m=0 state. Calix verifies the radial Schrodinger equation and both normalization integrals. Outputs include radial probability, cross-section contours and a probability-density surface.
- The atomic model fixes a point nucleus and neglects spin and relativistic corrections. The coil model neglects radiation, gravity and feedback. Model assumptions and nondimensional scales appear in the notebooks.
- Native C++/Boost now evaluates EllipticK and EllipticE with Wolfram/SymPy parameter m (Boost receives sqrt(m)). Adds LaguerreL, LegendreP, Pochhammer and FunctionExpand using existing SymPy. No new dependencies or license changes.
- Revised examples open with a new identity; existing user notebooks remain intact.
