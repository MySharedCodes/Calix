# 稳定版验收记录

本页区分已实现的保障、当前验证证据和仍需外部环境完成的项目。不能把 CI 配置文件存在视为 CI 已在远程执行。

## 验证命令

```powershell
.\.venv\Scripts\python.exe scripts/verify.py --tier core
.\.venv\Scripts\python.exe scripts/verify.py --tier numerical
.\.venv\Scripts\python.exe scripts/verify.py --tier examples --timeout 900
.\.venv\Scripts\python.exe scripts/verify-ui.py
.\.venv\Scripts\python.exe scripts/benchmark-core.py
```

每层将结果与日志保存在 `work/verification/`。核心层检查常用函数、单位、API 和会话、独立数值参考、工作空间编解码与撤销逻辑；数值层检查 SIMD 分派、线程预算、PARDISO、网格和 PDE 参考问题；完整案例层较慢，单独运行。超时算失败，不能把超时的案例列为通过。

浏览器验证需要 Playwright；设置 `CALIX_PLAYWRIGHT` 可使用已有模块。默认使用 Edge；`CALIX_BROWSER=chromium` 使用已安装的 Playwright Chromium。测试使用自己的服务端口和浏览器配置，包含损坏存储、配额不足、恢复副本、结构撤销和帮助操作。

构建桌面程序后运行 `node tests/desktop-recovery.cjs`，检查原生文件历史、恢复副本、进程退出后的磁盘恢复及偏好保留。它自行创建独立 WebView 配置、选择调试端口，并清理自己启动的进程，不连接现有用户窗口。截图及记录位于 `work/verification/desktop-recovery/`。

## 数据保护的范围

桌面版在应用配置目录 `recovery/` 保存完整工作空间最近副本和最多 20 个历史副本，正常历史间隔一分钟，结构操作触发额外检查点。更改停止约 400 ms 后排队写入；尚未写完的更改仍可能因突然断电丢失。

单次磁盘工作空间副本上限为 20 MB（未压缩 JSON）。超过上限或写入失败时会提示手动保存；已有副本保留。每个笔记文件仍受 10 MB 上限约束。

恢复历史按版本列出文档，选择后打开新副本。自动恢复会在 WebView 工作空间缺失或无法解析时尝试磁盘数据。浏览器预览只维护本地存储检查点，不具备桌面磁盘恢复能力。

覆盖保存源文件前，旧内容保存在相邻 `.calix-history/<原文件名>/` 中。当前已保存笔记的文件历史也可在恢复窗口访问。备份未加密；删除敏感文档时需要同时管理这些备份。磁盘写入失败会报告错误；副本不替代外部备份。

单元结构支持 20 步撤销／重做，文本有编辑器自己的撤销历史。恢复和撤销不回滚计算会话，结果会标为待重新计算。继续依赖计算前应全部运行。

## 小范围试用

建议至少 3–5 名未参与开发的学生或研究人员各自完成：安装、带单位计算、修改一个 ODE 案例、绘图、保存再打开、一次错误恢复。记录任务成功与否、卡住位置、错误表达式和耗时。先收集实际结果，再确定稳定版范围；不要预填通过。

## 发布判定

源码提交、锁文件哈希、源文件摘要和工具版本写入 `BUILD-INFO.json`。`scripts/release-check.py` 检查发行文件与哈希；`--public` 还会在许可证、仓库、签名和外部验收仍待定时拒绝标记公开发行就绪。详见 [发行准备](RELEASING.md)。
