# Calix 0.1.28

首次公开后的功能更新合并记录。

- 增强文字单元编辑，支持字号、样式、标题、公式和 Esc 特殊字符输入。
- 新增可搜索的笔记目录，改善长笔记阅读、定位和窄窗口布局。
- 增强 AI 操控方便性，完善计算速查、笔记交付和错误恢复说明。
- 改善首次计算速度，以及单位、矩阵和求和求积的计算体验。
- 增加清空输出、笔记恢复历史和单元操作撤销，方便整理与恢复计算过程。
- 窗口标题随界面语言切换，完善开源项目信息入口。
- 完善使用帮助、自动验证和开发文档。
