# Calix 0.1.18

- 海洋蓝皮肤改为一只跃起姿态的虎豚，替换重复鱼群；图案固定在背景右下方。
- 吊桥最后增加应力云图和 MPa 色标，显示桥面、四根桥塔、主缆和吊杆。
  变形视图也包含全部桥塔。计算单元使用 `GraphicsComplex`、`VertexColors`、
  `ColorData`、`BarLegend` 和 `Legended` 完成后处理。
- 桥塔由位移梯度计算三维 von Mises 应力；桥面取上下表面的膜应力与弯曲
  应力合成值。节点颜色来自相邻单元中心结果的算术平均。索显示含初张力的
  轴向应力，其余构件显示附加载荷应力。
- 机翼的流线叠加在速度云图上，压力系数仍单独显示。
- 缩短空气阻力案例的文字，保留直接输入 `650[gr]`、`890[m/s]`、`7[km]`
  及两种阻力模型的计算。
- `Min`、`Max` 支持原生数值数组及嵌套列表；三维多边形支持逐顶点着色，
  结果保存后保留颜色和色标。
- 大型工作空间自动保存采用无损压缩，避免多个有限元案例的图形结果占满
  本地存储。原有自动保存和 `.calix` 文件继续兼容。
- 新增 C++ 运行时指令集分派。双精度稠密矩阵乘法和适用的批量算术表达式
  支持 AVX2 / AVX-512；有符号 8 位整数矩阵支持 AMX-INT8，累加结果为精确
  32 位整数。普通浮点运算不会为使用 AMX 而降低精度。CPU 或系统未提供相应
  状态支持时使用回退路径。详细范围与实机验证情况见 `CPU-ACCELERATION.md`。

桥梁仍为已预张紧构型上的线弹性增量模型。单元中心应力的节点平均会平滑
局部峰值，塔顶连接处需独立细化；本例不构成工程设计验算。有限元积分和
稀疏求解沿用 C++ Eigen 核心。本次调试使用 8 Workers。
