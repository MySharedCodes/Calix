# 故障排查

适用版本：0.1.28。先保存正在编辑的文档，再尝试涉及重启的操作。

## 引擎离线或无法启动

1. 等待首次启动完成，使用状态栏的重新连接按钮。
2. 检查 Microsoft Edge WebView2 Runtime 是否可用。便携版应完整解压，保留 `backend`、`components` 和 `notices` 等目录。
3. 检查安全软件的拦截记录，核对安装包来源和校验值。不要直接关闭安全软件。
4. 开发模式下确认本地服务已启动、端口未冲突。浏览器预览通过 Vite 代理连接本机服务，不等于可独立计算的静态网站。

不要将 API 连接文件或完整日志原样上传；其中可能包含认证 token、本机路径和私人计算。

## 同一行代码在不同笔记本中结果不同

通常先检查变量赋值。例如先运行 `x=2`，后面的 `x^2` 会得到 `4`。用 `Clear[x]` 清除，或重启会话后从头运行。笔记本之间、笔记本与传统计算器之间的变量互不共享。

旧文件中的图与结果是保存的快照。重新打开、取消、超时或重启之后，先运行定义参数的单元。“全部运行”会重新建立当前文档的变量。

## 公式无法计算或出现空框

填完积分上下限、变量、被积函数等槽位，再按 Ctrl+Enter。特殊字符面板中的字符比求解器所支持的结构更多；漂亮的显示不能保证语义受支持。若仍失败，用一个最小源码表达式复现，例如 `Integrate[Sin[x],{x,0,Pi}]`，并在报告中附上输入方式及错误文本。

## 结果仍是符号或与预期不同

先核对大写函数名、常数 `Pi`、`E`、`I`，以及赋值 `=` 与方程 `==`。`pi` 是普通符号，不是圆周率。`FullSimplify` 不是完整 Mathematica 实现；有的表达式可能保持符号形式。

检查定义域、分支与精度；不要只比较屏幕上小数的末位。带条件的解要代回原方程。`NSolve` 和 `FindRoot` 的支持范围见 [语法参考](SUPPORTED-SYNTAX.md)。

## 单位报错

`3[m]+2[s]` 维度不同，应当报错。单位区分大小写；`g` 与 `gr` 不同。给未赋值符号附单位可用 `(x)[m]` 或 `Quantity[x,"m"]`。绝对温度与温差要区分。

自动选中的 SI 单位可能与任务中的物理名称不同。例如力矩与能量量纲相同；用 `UnitConvert[value,"N*m"]` 保留指定单位。

## 数值求解失败、超时或内存不足

先缩短区间、减小模型或只运行出错单元所需的定义。`FindRoot[f,{x,a,b}]` 要求端点变号。对 ODE 检查初值、奇点、区间和参数是否产生刚性。默认单次限时 180 秒；取消和超时会清空该会话状态。

Windows 工作进程有内存限制。增加 Workers 会提高并发资源消耗，不能直接解除单进程内存限制。机器可用内存不足时，减少同时打开并计算的任务。

## 设置了 8 Workers，CPU 没有跑满

Workers 是上限。只有实现并行的操作会使用多个线程；小于 512 行的稀疏系统会主动用单线程。符号计算、部分网格和后处理常为串行。输出的原生执行信息及 `/api/health` 可帮助判断路径，不能仅凭任务管理器瞬时占用率判断设置失效。

AVX2、AVX-512 和 AMX 还需要对应 CPU 与操作系统支持，且只适用于特定内核。没有支持时自动选择可用路径。AMX INT8 不用于把双精度科学计算降精度。见 [CPU 说明](CPU-ACCELERATION.md)。

## PDE module 缺失或模型不受支持

重新运行安装包并勾选 **PDE module**。便携版需要对应 `components` 内容；不要单独复制 DLL 替代整个模块。

安装模块并不等于支持全部 Mathematica PDE 语法。当前只支持文档列出的模型、单元和边界条件。齿轮接触、流场与桥梁例子都含建模假设，网格云图不能代替收敛性与物理验证。见 [PDE 范围](PDE.md)。

## 滚轮只滚动页面，图没有缩放

先点击需要交互的图，再使用滚轮。这样浏览长笔记时不会意外改变图。笔记本整体缩放用 Ctrl+滚轮；工具栏百分比可恢复 100%。

## CLI 导出的笔记打不开或缺结果

优先用 `calix-cli.exe eval --file problem.wl --notebook answer.cixnb` 生成文件，避免手写 JSON。然后运行 `calix-cli.exe validate answer.cixnb` 检查结构与语法。验证通过不代表所有计算已成功；还要检查退出码、JSON 中的 `ok` 和实际输出。

输入 `.wl` 使用 UTF-8。CLI 接受 UTF-8 BOM，但其它编码可能损坏希腊字母与角标。保存结果后的 GUI 会话是新会话，继续依赖计算前重跑定义。见 [API](../API.md)。

## 设置没有保存

确认退出前已完成修改。正常桌面配置会持久保存偏好；浏览器开发模式使用该浏览器自己的本地存储，与安装版不共享。更换 Windows 用户、清理应用数据或使用隐私窗口也会得到新的配置。不要为了修复设置先删除整个数据目录；先导出并备份笔记。

## 提交可复现报告

请提供版本、Windows 版本、安装组件、最短输入、完整错误文本、预期结果和验证依据。说明“全部运行”还是单独运行，并注明 Workers、精度及是否先给变量赋值。敏感输入先替换为可公开的数据。使用 [贡献指南](../CONTRIBUTING.md) 中的模板。
