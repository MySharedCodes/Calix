# Calix 使用帮助

适用版本：0.1.27。按 F1 或点击侧栏“帮助”可离线阅读。英文入口见 [English overview](../README.md)。

## 工作空间与文件

**CIX Notebook** 把计算单元、文字单元和结果保存在同一份文档中。侧栏管理多个笔记本；每个笔记本有独立变量会话。标题可以直接编辑。新建文档名为 Untitled CIX notebook。

“保存”写回当前文件，“另存为”选择新路径。推荐扩展名 `.cixnb`；已有 `.calix` 文件也可打开。文件保存输入、公式和结果，不保存正在运行的进程。重新打开后，已有结果标为“待重新计算”，继续计算前应从定义变量的单元开始运行。

管理栏支持切换、复制、改名和打开文件位置。移除管理栏条目与删除磁盘源文件是两个操作；选择删除源文件会再次确认。自动恢复工作空间便于续写，但不能代替在磁盘上保存和备份。

**传统计算器面板** 使用相同的计算单元编辑器和独立会话，适合临时计算。它只有一个输入单元，不能添加单元或保存笔记。需要保存过程时使用 CIX Notebook。

## 运行与变量

在单元内按 **Ctrl+Enter** 或点击左侧运行按钮。一次输入多行，会按行输出；行末 `;` 隐藏中间结果。系统最多显示每个单元的 40 个结果。

```wolfram
a = 3;
b = 4;
a^2 + b^2
Sqrt[a^2 + b^2]
```

结果依次为 `25`、`5`。`=` 赋值，`==` 构造方程，`Clear[a,b]` 清除赋值。请先定义参数，再运行使用它的单元。

“全部运行”先重启当前笔记会话，再从上到下运行。编辑、重排单元后，下游旧结果会标记过期。单独运行一个单元不会自动重算它依赖的所有上游定义。

按 **Alt+.** 或停止按钮放弃计算。超时和取消会终止对应工作进程、清空该会话变量；之后请重新运行定义。重启会话也清除变量，但保留文档中的输入和旧输出。

输出旁的复制按钮复制可再次计算的文本；相邻的向下按钮将结果放进新建的下一行输入。图形与动画有各自的工具栏。

## 语言与精度

Calix 实现 Wolfram 风格语言的一个子集。它不依赖 Mathematica，也不能执行任意 Mathematica 程序。函数名区分大小写，函数参数用 `[]`，列表用 `{}`，分组用 `()`，幂用 `^`。建议显式写 `*`，避免长变量名与隐式乘法混淆。

```wolfram
1/3 + 1/6
N[Pi, 50]
Det[{{1,2},{3,5}}]
Expand[(x+1)^4]
```

整数和分数尽量保留精确形式。`N[expr,digits]` 请求近似值，支持 2–1000 位；这不代表原生数值求解器也有任意精度。原生求根、积分、ODE 和常规绘图采用双精度浮点。偏好设置中的有效位数也不能恢复已丢失的浮点精度。

目前不支持任意模式匹配、自定义延迟函数、包加载、文件读写或进程命令。未知函数保留符号形式时，不代表已经完成计算。更完整的函数范围见 [语法参考](SUPPORTED-SYNTAX.md)。

## 公式与特殊字符

计算单元同时支持源码与排版公式输入，传统计算器也一样。按 Esc，在光标附近的浮层中输入缩写，再按 Esc 或 Enter 选择。也可点击特殊字符按钮查找，悬停查看打法。

| 按键或缩写 | 输入 |
|---|---|
| Ctrl+6 | 上标框 |
| Ctrl+2 | 根号框 |
| Esc a Esc | α |
| Esc b Esc / q Esc / p Esc | β / θ / π（每次从 Esc 开始） |
| Esc intt Esc | 不定积分模板 |
| Esc dint Esc | 定积分模板 |
| Esc sum Esc / prod Esc | 求和 / 求积模板 |
| Esc lim Esc | 极限模板 |
| Esc frac Esc / sub Esc | 分式 / 下标模板 |
| Esc pdiff Esc | 偏导模板 |
| Esc mat Esc / vec Esc | 矩阵 / 向量模板 |
| Esc sc Esc | 花体字母模板 |

模板直接留在输入处，以排版公式显示。填写全部空框后用 Ctrl+Enter 计算，Tab 可在模板槽位间移动。未填完的模板会报错，不会作为完整表达式发送。字符能显示，不表示所有数学结构都已有求解器；复杂或不支持的结构请改用文档列出的函数。

## 单位与角度

```wolfram
3[m] + 20[cm]
UnitConvert[72[km/h], "m/s"]
2[kg]*3[m/s^2]
UnitSimplify["kg*m/s^2"]
Sin[90°]
```

结果中的单位带中括号，乘积显示为点、商显示为 `/`；输入仍可用 `*`。单位由 Pint 提供，包括 SI 前缀与大量非 SI 单位，大小写有区别。未知单位或维度不兼容会报错。角度不带 `°` 时按弧度处理。

`g` 是克，`gr` 是 grain（格令）。符号量可写 `(x)[m]` 或 `Quantity[x,"m"]`，避免与 `f[x]` 函数调用混淆。温标转换用 `UnitConvert[0[degC],"K"]`；温差用 `delta_degC` 等单位。

自动化简只依据量纲，不能区分能量与力矩等物理含义。要保留目标表示，请显式 `UnitConvert[expr,"N*m"]`。带单位的任意符号方程还不支持普遍的自动无量纲化。见 [统计与单位](STATISTICS-AND-UNITS.md)。

## 代数、微积分与方程

```wolfram
Factor[x^4-1]
Simplify[(x^2-1)/(x-1)]
Series[Sin[x], {x,0,7}]
D[Exp[-x^2], x]
Integrate[x^4 Exp[-3 x^2], {x,-Infinity,Infinity}]
Solve[{x+y==3, x*y==2}, {x,y}]
DSolve[{y'[t]+2 y[t]==0, y[0]==3}, y[t], t]
RSolve[{u[n+1]==2 u[n]+1, u[0]==0}, u[n], n]
```

解析积分与解方程可能返回特殊函数、条件或未求值表达式。核查解的定义域和约束；化简消掉因子后，还要保留原式的禁值。`FullSimplify` 当前与 `Simplify` 共用实现。

`Solve` 的单变量实数域写法和部分条件受支持；方程组请用两个参数的 `Solve[equations,variables]`。`NSolve` 对有限符号解做数值化，并不是通用的非线性数值搜索器。

## 数值求解与统计

```wolfram
FindRoot[Cos[x]-x, {x,0,1}]
NIntegrate[Exp[-x^2], {x,-3,3}]
v = NDSolveValue[{y'[t]==-y[t],y[0]==1}, y[t], {t,0,5}];
Plot[v[t], {t,0,5}]
Fit[{{0,1},{1,3},{2,5},{3,7}}, {1,x}, x]
Mean[{2,3,5,7,11}]
Variance[{2,3,5,7,11}]
```

`FindRoot` 的两个端点必须形成变号区间，它们不是两个初始猜测。数值 ODE 是初值问题；初值应放在时间区间左端，结果不能在区间外取值。ODE 的步进误差和插值误差不同，极端参数、刚性问题需要额外检查。

`Variance[data]` 用样本方差，分母为 `n-1`。经验分位数不插值，峰度不是超额峰度；统计检验和拟合的条件见 [统计参考](STATISTICS-AND-UNITS.md)。

## 绘图与动画

```wolfram
Plot[{Sin[x],Cos[x]}, {x,-Pi,Pi}]
ParametricPlot[{Cos[3 t],Sin[2 t]}, {t,0,2 Pi}]
ContourPlot[x^2-y^2, {x,-3,3}, {y,-3,3}]
Plot3D[Sin[x] Cos[y], {x,-Pi,Pi}, {y,-Pi,Pi}]
Animate[Plot[Sin[x-a], {x,0,2 Pi}], {a,0,2 Pi}]
```

先点击图形，才激活滚轮缩放；未激活时滚轮用于滚动页面。二维图可平移、复位、导出 PNG；三维图可旋转和缩放。动画提供播放、暂停和进度控制。曲线采用有限采样，不连续点或窄峰可能需要缩小范围或增加 `PlotPoints`。

`Plot2D` 在 Calix 中表示密度图。任意 Mathematica 绘图选项和通用 `Manipulate` 并非全部支持；请从“后处理”中的实际示例开始。

## 文字单元

点击“文字单元”添加 Markdown，双击预览或点击编辑图标修改，Shift+Enter 回到预览。支持标题、列表、表格、代码块、行内 `$...$` 与独立 `$$...$$` 数学公式。文字不会执行；计算放在计算单元中。保存文档时文字一起保存。

## 偏好设置与资源

语言、皮肤、有效位数和最大 CPU Workers 会持久保存。基础界面提供中文与英文，其余语言、扩展皮肤和 PDE module 按安装时的可选组件提供。缺少 PDE module 时，调用相应功能会提示安装。

Workers 初始值是本机物理核心数。它限制并发计算进程和支持并行的原生操作；符号化简、网格生成和部分后处理不会因此自动占满所有核。输出中的执行信息报告实际路径和线程设置。详见 [CPU 执行说明](CPU-ACCELERATION.md)。

默认每次计算限时 180 秒。输入上限 24000 字符；笔记本 1–200 个单元，文件最大 10 MB。很大的图形结果也会增加保存文件大小。API 可在规定范围内设置超时；见 [API](../API.md)。
