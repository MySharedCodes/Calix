# Calix Official Brand Mark

The user approved the current C-arc and I-stroke mark on 2026-10-28.
It replaces the original letter-C and accent-dot mark.

## Production Assets

- `official/calix-mark.svg`: approved vector master snapshot.
- `official/calix-mark.png`: 512 x 512 application icon.
- `official/calix-mark.ico`: Windows multi-resolution icon.
- `frontend/public/calix-mark.svg` (project root): UI and browser favicon.
- `src-tauri/icons/icon.png` and `icon.ico` (project root): desktop build icons.
- `scripts/create-icon.py` (project root): raster icon generation.

## Approved Appearance

The background is teal (#087e80); both strokes are white (#ffffff).
The 2026-10-29 revision keeps the mark without serifs. Both strokes have
width 7 in the 100-unit viewBox. The I uses constant width and round ends
with radius 3.5 (diameter equal to stroke width), as approved on 2026-10-29.
The I stroke keeps its approved angle and extended lower end. The C arc
uses the final approved rotation and rightward/downward offset.
Do not replace this mark with an earlier gallery candidate.

The `Calix-logos-*` galleries are historical design explorations only.
This approval records the product's chosen brand artwork; it does not
represent trademark registration or legal clearance.

Source asset changes appear in desktop binaries only after rebuilding.
