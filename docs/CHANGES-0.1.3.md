# Calix 0.1.3

- Workspace notebook manager supports new/open, switching, renaming, duplication and removal. Each notebook retains its own cells, outputs, title, file path and live evaluation session. Workspace inputs autosave across restarts; legacy single-notebook autosaves and legacy math cells migrate on first use. Removing a workspace copy does not delete disk files. The local workspace supports up to 100 notebooks; export `.calix` files for archival and if browser storage fills up.
- Examples now open separate notebooks with titles exactly matching their displayed library entries. Existing notebooks stay in the workspace. Repeated selection still rotates between available variants. Named example files are exported by `node scripts/export-library.cjs`.
- Explicit calculations include fourteen examples: the previous ten plus matrix multiplication, determinant, inverse and transpose.
- Added analytical Minimize/Maximize and native FindMinimum/FindMaximum examples with plots. Analytical extrema support a single real variable, optionally bounded with `{x, lower, upper}`. Numerical extrema use the existing Boost-licensed C++ core and bounded Brent optimization: use a continuous finite unimodal objective over finite bounds; a global optimum for a multimodal function is not guaranteed. Results contain objective value and optimizer location. An empty analytical location mapping indicates an unattained extremum/infimum or unresolved location.
- Preferences persist numerical precision, Chinese/English UI language and maximum CPU Workers. Worker limit ranges from one to the number of logical CPUs. The service enforces the cap with a shared reusable process pool and separate serialized notebook environments. Calculations queue when all workers are occupied. Changing the cap during active calculations is rejected; cancelled/timed-out workers are replaced. A single calculation is not automatically parallelized.
- One calculation cell replaces the former code/math cell types. Write Wolfram-style source and insert 2D formulas at the cursor using the formula button, Ctrl+2 for a radical, or Ctrl+6 for a superscript. The formula composer inserts into the same canonical code, preserving multi-line code. Shift+Enter in the formula composer inserts the formula; Shift+Enter in the calculation cell runs it.
- Brand subtitle is now `Calculation & Interactive Xpressions`; the document subtitle is removed.
- Thirty original SVG logo concepts are available in `docs/branding/Calix-logos-30/index.html`, with selection, SVG downloads, dark/monochrome and small-size comparisons. Existing application icon remains pending a selection.
- No new third-party dependencies; the native optimizer uses the already distributed Boost components and license.
