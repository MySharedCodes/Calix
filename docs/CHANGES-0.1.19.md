# Calix 0.1.19

- 安装向导加入 Calix 商标、品牌侧图、页眉和 Calculation & Interactive Xpressions 字样。PDE、小语种、皮肤组件仍可分别选择安装。
- Esc 特殊字符面板在输入光标附近悬浮，支持搜索与连续插入。新增 script、Fraktur、双线体、粗体字母及常见课堂数学符号；`sc`、`sca`、`scA` 可插入脚本体模板或字母。
- 积分、求和、求积、分式、根式、上下标、矩阵等模板确认后在计算单元中保留排版，可点击继续编辑。公式随 notebook 保存，并支持边界输入、删除和撤销。
- “解析与符号计算”中的偏微分方程解析解移至该组最后。
- 新增“石英与空气：电磁波反射和透射”。结构化四边形 TE Helmholtz 有限元，输出电场、反射率、透射率和能量平衡，并与菲涅耳解比较。
- 新增“齿轮啮合：接触与扭矩传递”。渐开线轮廓和结构化环状四边形网格，显式组装弹性与无摩擦罚接触系统，显示孔边反力矩、接触节点力和 von Mises 应力。
- 修正吊桥弹性系数张量的导数索引顺序，并用刚体运动和常应变能量检验验证。
- 完善符号列表与原生数值数组混合运算、向量点积及原生数值统计的处理。

## 算例范围

石英案例为无吸收、法向入射、普通光的二维模型，一阶辐射边界对本例平面波适用，不代表一般散射或完整各向异性电磁模块。默认网格的反射率误差需要结合加密结果评估。

齿轮案例为一个啮合位置的小转角静态接触增量，采用二维平面应力、节点到线段的无摩擦罚接触；不包含整周大转动、动力学、摩擦或真实加工齿根圆角。接触力为离散节点力，不能当作接触压力；峰值应力需做网格与罚参数收敛检验。

特殊字符采用自建 Unicode 字符表与数学输入组件，支持常用课堂结构和字母，不代表 Mathematica 13 全部字符及语言语义兼容。
